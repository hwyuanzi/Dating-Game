# Ariadne 1.1

可直接运行的单文件代码是 [submission/bot.py](../submission/bot.py)。
它同时实现 P、M 和官方 NDJSON 通信接口，只导入 `json`、`sys`、
`random`、`math`、`time`，没有本地模块、第三方库、模型文件或联网依赖。

```sh
python3 submission/bot.py
```

程序从标准输入读取裁判的 JSON 消息，每行输出一个及时刷新的 JSON 回答。
不要将它当作需要命令行选择 P/M 的脚本；角色由裁判的消息决定。

## 改进

P 保留整数分单位的合法性计算和动态规划：在每轮可改坐标数、相对于原始
权重的 ±20% 范围、正负权重分别归一化的限制下，精确压低当前候选的评分。

M 保留初始精确方程、离散贝叶斯推断、六符号编码及固定幅值残差搜索，增加：

- 对可能的 `0、±0.02` 或 `0、±0.04` 权重，一次编码探测四个坐标。
- 先用两个单坐标读数检查该假设，优先检查预测幅值最大的坐标；不符即回退。
- 对固定幅值和上述三值模型，围绕二进制候选向内扰动，保留探测轮的得分机会。
- 在推断出的分单位网格上反推原始权重范围，避免把可变的当前读数直接当作原始值。

对普通非均匀模型保留原先的探测方式。实测表明，无条件地将所有模型都改为
二进制候选周围的扰动，会损伤部分可变权重对手的成绩，因此该变体没有保留。

## 复现和打包

```sh
python3 -m unittest discover -s tests
python3 tools/benchmark.py --n 100 200 --seeds 3 --role m --distributions sample person-mixed variable mutable coarse --adaptive --output results/ariadne-benchmark.json
python3 tools/package_compact_bot.py
python3 tools/verify_submission.py --n 20 40 60 100 200 --seeds 3 --output results/ariadne-package.json
```

打包工具默认直接使用仓库中的单文件，不需要开发时的分拆模块。输出的
`dist/compact/dating-hy2821.zip` 只包含 `hy2821/bot.py` 和 `hy2821/SUBMISSION.md`，
并附带 ZIP 与文件的 SHA-256 清单。验证器拒绝额外文件、重复路径和符号链接。
基准工具保存源码快照、源码哈希、具体候选及评分轨迹，不向 M 暴露 P 的权重。

代码本身可以作为单个 `.py` 文件运行。当前官方交付格式仍是完整 ZIP 和
`SUBMISSION.md`，自定义入口需要架构方检查；只发送 `.py` 附件是否被接受，
应由架构方确认。

有界解码和幅值模型仍是推断假设，未被探测到的越界权重可能发生编码混叠。
两个验证读数降低误判风险，不能证明所有坐标都属于该模型。正式参数及主机
环境公布后，应按这些参数重新验证。
